# Module 15 Project — Final Assessment

**Time:** one 90-minute session plus a written review. Do this when the eight mocks are done.

## Part A — The unseen problem (90 minutes, recorded)

Pick a problem you have **not** worked through in this course. Good choices:

- Design a food-court ordering system (multiple kitchens, one counter, order tracking)
- Design a gym class booking system (capacity, waitlists, cancellations, recurring classes)
- Design a document permission system (users, groups, inherited folder permissions, sharing links)
- Design a stock-trading order book (limit and market orders, matching, partial fills)
- Design a parking valet system (no spot numbers; cars are stacked and must be retrieved)

Run the full Module 10 time-box. Produce:
1. Three scope lists
2. Actors, use cases, noun/verb table, 2+ implied entities
3. A Mermaid class diagram with multiplicity
4. The public API plus one sequence diagram
5. Variation sentences and an edge-case list
6. Compiling Swift for the core path with a `demo()`
7. Three things you'd do with more time

## Part B — Self-review (written)

Grade Part A with the Module 15 §2 sheet. Then answer:

1. Which DESIGN step overran, and by how much?
2. Which implied entity did you find, and at what minute? (Earlier is better.)
3. Name every abstraction you introduced and its variation axis. Which one would you delete?
4. How many edge cases did you name unprompted? Which category did you miss?
5. If the interviewer said "now add X", which X would hurt most, and why?
6. Replay your recording at 2× and count the silences over 20 seconds.

## Part C — The portfolio

Assemble, in one folder:
- Your best three module projects (Modules 07, 12 or 13, and 14 are the usual picks)
- Your `PatternExam.md` from Module 08
- Your `PROGRESS.md` mistake log
- This final assessment

This is both revision material and, for some companies, something you can genuinely share.

## Completion bar

You have finished this course when:

- [ ] All 16 module checkpoints answered aloud from memory
- [ ] Every `swift test` target green, written by you
- [ ] All 14 module projects built and self-graded
- [ ] 8 mocks recorded, last three averaging 42+/50
- [ ] Final assessment scored 42+/50
- [ ] Mistake log reviewed and its recurring items drilled to extinction

## After the course

- **Weekly:** one 45-minute problem from a list you haven't touched. Rotate easy/medium/hard.
- **Monthly:** re-run the Module 08 drills; re-read your mistake log.
- **Continuously:** apply it at work. The fastest way to keep this sharp is to name the variation axis out loud in every code review you do.
